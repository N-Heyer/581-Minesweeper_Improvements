# 581-Minesweeper_Improvements — Project Board

All tickets and sprint work for this repository are tracked on our GitHub Project board:

**[Open the Minesweeper Improvements Project Board](https://github.com/users/RockettKings/projects/2/views/1)**

## How to use the board

- **Backlog** — tickets not yet started
- **In progress** — tickets someone is actively working on
- **In review** — work waiting on a pull request review
- **Done** — merged and complete

Assign yourself to a ticket before moving it to **In progress**.
